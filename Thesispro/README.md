# ThesisPro Germany

Professional one-page website for MBA and Master's thesis support services.

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal, usually `http://localhost:5173/`.

## Build

```bash
npm run build
npm run preview
```

## Project Notes

- Built with React and Vite.
- Main website code is in `src/App.jsx`.
- Styling is in `src/App.css` and `src/index.css`.
- The hero image is stored in `src/assets/thesis-consultation.jpg`.
